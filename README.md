# پیدا کردن اعداد و کلمات بزرگ در یک متن با استفاده از Regex

**توضیح کامل:**
در این کد ابتدا یک جمله نمونه تعریف شده است.  
سپس دو تابع تعریف می‌شوند:  
۱. تابع `find_num`:
با استفاده از الگوی r"\d+" تمام اعداد موجود در جمله را پیدا کرده و تعداد آن‌ها را نمایش می‌دهد. 

۲. تابع `find_upper_word`:
با استفاده از الگوی `"r"\b[A-Z][A-Za-z]*\b` تمام کلماتی را که با حرف بزرگ شروع می‌شوند شناسایی کرده و تعداد آن‌ها را همراه با لیست کلمات چاپ می‌کند.  
هر دو تابع با استفاده از کتابخانه `re` نوشته شده‌اند.
